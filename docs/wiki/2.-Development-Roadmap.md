# 2. Development Roadmap

**Classic Games. Real Algorithms. Practical Engineering.**

STRATUM-83 is now designed as a **clean retro game collection**, with two main views: **GAMES** for human-versus-computer play and **ALGORITHMS** for short explanations of the methods used.

| Game | Computer technique | Status |
| --- | --- | --- |
| Grid Zero | Minimax / alpha-beta pruning | Playable |
| Labyrinth | A* shortest-path benchmark / fog of war | Playable on development branch |
| Checkers | Minimax / heuristics | Proposed |
| Blackjack | Probability / Monte Carlo | Proposed |
| Chess | Search / heuristics | Proposed |
| Crisis Protocol | Rule-based agents | Planned |

### New Labyrinth

The maze is now **23×31**, with loops and multiple routes. You navigate **only using arrow keys**, seeing nearby cells inside a limited line of sight. Unseen areas remain black; explored areas remain dim. The computer uses A* to compute a shortest route. Its path and length are hidden until you reach the exit.
