# STRATUM-83 — Research & Learning Center

Welcome to **STRATUM-83**, an independent, non-commercial, offline Java research terminal.

**Play, experiment, understand.** The application separates interactive games from reproducible research so that you can learn what happens behind every decision.

## Play

- **Grid Zero** — classic 3×3 tic-tac-toe against perfect-play Minimax, with a two-player `DUEL` command.
- **Labyrinth** — navigate an original, seeded maze using the keyboard or mouse.

## Research Lab

- **Minimax vs Random:** choose a seed and game count; compare wins, draws and losses.
- **Pathfinding Benchmark:** choose a seed and maze count; compare BFS, Dijkstra and A* using equal inputs and report average shortest-path steps and explored cells.
