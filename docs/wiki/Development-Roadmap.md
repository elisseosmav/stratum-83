# STRATUM-83 — Development Roadmap

**Classic Games. Real Algorithms. Practical Engineering.**

STRATUM-83 is a free, independent Java research project. Every game should eventually provide Play → Trace → Explain → Apply. **Release versions are plans, not promises of calendar dates.**

| Release | What it covers | Status |
| --- | --- | --- |
| v0.1 | Grid Zero and classical Minimax | Original source version |
| v0.2 | Windows quality, CI and installer | Planned / partially underway |
| v0.3 | Grid Zero and Labyrinth Play/Trace/Explain/Apply lessons; pathfinding Research Lab | Beta 1 published; redesigned Beta 2 candidate |
| v0.4 | Fictional strategic crisis simulation | Planned |
| v0.5 | Checkers and heuristic game-tree search | Proposed |
| v0.6 | Blackjack and Monte Carlo probability | Proposed |
| v0.7 | Chess and deeper search | Proposed |

The **v0.3.0-beta.2** candidate proposes three main-menu programs (Grid Zero, Labyrinth and Research Lab), terminal-only `HELP`/`EXIT`/`DUEL`, and configurable **results-only** experiments, and a Labyrinth search visualization and practical weighted-routing exercise. It is not yet a published Release.
