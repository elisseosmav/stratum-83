# STRATUM-83 — Development Roadmap

**Classic Games. Real Algorithms. Practical Engineering.**

STRATUM-83 is a free, independent Java research project. The main menu is a retro game catalog first; algorithm details and research remain optional. **Release versions are plans, not promises of calendar dates.**

| Release | What it covers | Status |
| --- | --- | --- |
| v0.1 | Grid Zero and classical Minimax | Original source version |
| v0.2 | Windows quality, CI and installer | Planned / partially underway |
| v0.3 | Two playable classic AI games and optional Minimax/pathfinding research | Beta 1 published; redesigned Beta 2 candidate |
| v0.4 | Fictional strategic crisis simulation | Planned |
| v0.5 | Checkers and heuristic game-tree search | Proposed |
| v0.6 | Blackjack and Monte Carlo probability | Proposed |
| v0.7 | Chess and deeper search | Proposed |

The **v0.3.0-beta.2** candidate now presents **six games** in its main menu: Grid Zero and Labyrinth are playable; Crisis Protocol is planned; Checkers, Blackjack and Chess are proposed. Each entry identifies a fundamental AI algorithm, while unfinished games remain disabled. Research Lab can still be opened through the `RESEARCH` command. Beta 2 has **not** been published.
